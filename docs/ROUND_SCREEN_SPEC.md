# 猜词回合屏 — 垂直切片规格 V0.1

## 范围
只做猜词回合这一屏及必要的本地状态切换。暂不铺首页、模式大厅、完整房间大厅、个人资料和商城。

## 信息层级
1. 答案：描述者/表演者可见，最大字号；其他玩家不得看到。
2. 当前模式与规则：清楚显示口头描述或动作表演及行为限制。
3. 倒计时：明显但次于答案；最后10秒进入高注意状态。
4. 脑洞指令：独立指令条，与模式规则不能冲突。
5. 操作：猜对、跳过；位置稳定，防误触。
6. 上下文：队伍/当前玩家/本轮分数简洁呈现。

## 两种模式共享布局
- 口头描述：剪纸话筒；规则“用语言描述，队友猜”；可显示禁止词。
- 动作表演：剪纸手势；规则“不能说话，只能表演”；不显示语言描述专用禁止词。
- 模式差异由 MODE_ASSETS.json 和规则配置驱动，不复制整页。

## 交互状态
ready、playing、last_call、correct_feedback、skipped、round_finished。

## 边界情况
- 答案长短：1–32个汉字均需检查；超长自适应字号与换行。
- 指令支持2–3行，不挤压操作按钮。
- 小屏幕与字体放大时主要操作始终可达。
- 快速连点时操作幂等，反馈期间禁用重复提交。
- 联机版由服务端状态控制，不用客户端计时结果判分。

## 首轮测试数据
每种模式15道题。数据与 UI 分离，覆盖短答案、长答案、别名和易误解词条。

## 验收
- 两种模式使用同一组件树。
- 切换模式只改变配置、提示和可见区域。
- 所有题目文字动态渲染，无单题专属背景图。
- 长文本与最后10秒状态通过截图检查。
- 联机版本由服务端强制保证答案可见权限。
