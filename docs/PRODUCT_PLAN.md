# 产品规划与竞争策略

## 产品定位
《开个脑洞》是以表达创意为核心的多人聚会桌游。核心回合：抽题 → 获得表达规则/脑洞指令 → 描述或表演 → 队友猜测 → 计分。

## 差异化假设
1. 双卡组合：题目卡决定猜什么，指令卡决定怎么表达。
2. 可识别美术语言：原创统一视觉，秘密任务卡成为品牌识别物。
3. 低准备成本：微信房间、短回合、清楚的当前任务状态。

以上均为待验证假设，不是已证明的竞争优势。比较纯猜词与双卡玩法的趣味评分、规则理解时间、有效猜中数和主动再玩意愿。

## 当前范围：猜词回合垂直切片
只做一屏及必要状态：模式标识、题目（仅表演者可见）、脑洞指令/动作限制、60秒计时、猜对/跳过、简洁队伍/回合信息。模式切换时同一组件按配置改变提示与规则。

暂不做完整首页、商城、排行榜社交、账号系统、复杂房间大厅。

## 首轮验证
- 口头描述：15道题。
- 动作表演：15道题。
- 覆盖短词、长词、别名、易混淆题、不同动作难度。
- 同一套 UI 组件切换模式。
- 观察规则理解、答案可读性、长内容溢出和再玩意愿。

小样本只用于发现问题，不可宣称市场验证成功。
