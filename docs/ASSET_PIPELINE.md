# 批量素材生产线

## 核心原则
一套视觉母版 + 可复用图形组件 + 模式配置 + 程序化导出。题目和指令是数据，不是一题一张图。

## 资产分层
1. 品牌母版：卡片外轮廓、斜切纸边、纸层阴影、边角编号、字体层级、纹理与红黑米白色板。
2. 通用剪纸图形：秘密文件夹、目标圆点、放大镜、话筒、手势、对话框、印章、箭头、警戒条纹。
3. 模式包：名称、强调色、图标、纹样、规则提示和允许动作。
4. 题包：只有数据与可选封面，不为单题制作图片。
5. 专题封面：少量独立视觉叙事可用原创插画/AI 生图，单独审核。

## 批量生产流程
1. Claude 提交母版方向和3个代表图标：秘密任务卡、话筒、手势。
2. 审定 SVG 网格、描边、纸边切角、色彩和字体规则。
3. 将母版拆成可组合 SVG symbols / CSS components；图形与文字分离。
4. 模式配置 JSON 引用图标、颜色、纹样与规则提示。
5. 构建脚本按配置批量生成模式封面、图标集、卡牌预览和总览图。
6. 自动检查 SVG 引用、viewBox、尺寸、文件大小、缺失资产、对比度和长文案布局。
7. 人工检查不同屏幕与真实微信渲染；记录资产版本。

## 动态文字排版
题目、禁止词、指令、计时、分数由小程序组件实时排版。长答案自动换行/字号阶梯；文字与图形装饰分层，不烘焙进背景图。

## 何时使用 AI 生图
仅用于专题封面、活动主视觉或确实无法用矢量组件表达的独立插画。禁止逐题生成答案卡图片，禁止 AI 自由发挥同一套图标。

## 资产清单字段
asset_id, path, asset_type, source, author_or_model, license, created_at, version, used_by, notes。
