# 批量素材生产线

## 核心原则
一套遵循 `spy-titles` 约束的视觉母版 + 可复用纸片/字体/纹理组件 + 模式配置 + 程序化导出。题目和指令是数据，不是一题一张图。

## 风格约束参照
以用户已有仓库中的 `blender/lemo_style_guard/profiles/spy-titles/RULES.md` 与 `contract.json` 为内部研究入口。上游为 Lemo-Opuscar by Lemomo (LemoLab)，原始风格为 60s Spy Title Sequence。

转译时保留四墨、无渐变平色墨块、手剪边、纸片切缝与纸影、轻微纸纤维/漏墨、强对角线、大面积底色、文字结构性。不可把它降级为普通剪影风、光滑扁平 SVG 图标集或半色调网点风。

## 资产分层
1. **视觉母版**：四墨色板、卡片/纸片形状、局部空间固定的手剪边、切缝、小纸影、纸纹/纤维/漏墨层、标题字形规则、对角线构图。
2. **通用图形资产**：秘密任务符号、话筒、手势、文件夹、目标标记、印章、箭头等。每个图形都使用同一套纸边、纸影和墨色逻辑，不是随便拼一组剪影。
3. **模式包**：名称、颜色角色、图形资产、辅助纹样、规则提示和允许动作。
4. **题包**：只有数据与可选专题封面，不为单题制作图片。
5. **专题封面**：少量独立视觉叙事可使用原创插画/AI 生图，需遵循同一合同并单独审核。

## 批量生产流程
1. Claude 先研究用户的 spy-titles 规则，提交视觉解析：哪些是原约束、哪些是小程序转译建议。
2. 提交一张猜词回合屏的静态构图方案，以及任务卡、话筒、手势三个代表性素材。
3. 审定纸片边缘、切缝、纸影、纸纹、四墨颜色职责、字形与对角线规则。
4. 建立母版文件：图形、纸边、纸影、纸纹、文字分别分层；所有轮廓切边固定在自身局部坐标。
5. 将模式配置 JSON 映射到已审定的图形/颜色角色/纹样。
6. 构建脚本按配置批量生成模式卡、图标集、预览和总览图。
7. 自动检查 SVG 引用、viewBox、尺寸、文件大小、缺失资产、颜色数量和长文案布局。
8. 人工检查实际小程序渲染，记录资产版本。

## 动态文字排版
题目、禁止词、指令、计时、分数由小程序组件实时排版。文字本身也应作为构图元素处理：标题可参与卡片结构，不能一律缩成普通 UI 标签；同时保证可读性。禁止把每道题的文字烘焙进独立背景图。

## 何时使用 AI 生图
仅用于专题封面、活动主视觉或确实需要独立插画的内容。禁止逐题生成答案卡图片，禁止 AI 自由发挥同一套图形资产。
