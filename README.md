# 开个脑洞 · Open Your Mind

> 一款以脑洞表达为核心的微信多人聚会游戏。

**当前阶段：V0.1 产品定义与猜词回合垂直切片。**

## 产品方向
- 核心体验：朋友通过微信进入同一房间，轮流描述/表演，让其他玩家猜词。
- 差异化假设：题目卡 + 脑洞指令卡，让同一题在不同局产生不同表达挑战。
- 首屏范围：先把猜词回合页做好，不铺完整大厅和所有页面。
- 主视觉：复用用户已有 Lemo 风格库中的 `spy-titles`（60s Spy Title Sequence）约束作为设计参照。不是泛化的剪影风，也不是单纯红黑配色的扁平矢量风。

## 视觉方向
以原 `spy-titles` 的核心约束为参照：四种主墨色、无渐变平色墨块、固定手剪边、纸片切缝与小纸影、轻微纸纤维/漏墨质感、强对角线、大面积底色，以及文字参与画面结构。具体色值可调整，但需保留四墨角色关系。应用界面将其转译为可读、可交互的秘密任务卡与猜词回合屏。

风格来源与适配边界见 [视觉合同](design/VISUAL_CONTRACT.md)。原风格资料由 Lemo-Opuscar by Lemomo (LemoLab) 创作；本项目只记录风格参照和独立实现要求，不复制上游素材、源代码或整段规则文本。上游文档含 CC BY-NC 4.0 条款及额外许可，商业发布前必须单独核实授权范围。

## 批量素材原则
**题目和指令是数据，不是一题一张图。** 题目文字由小程序动态排版；图形素材来自经过审定的母版、纸边/纹理/印章/图形组件和模式配置。只为少量专题封面制作独立插画。

## 验证策略
先做「口头描述」和「动作表演」两种玩法，各 15 道测试题，共用同一套回合组件。验证布局、规则切换、长题目排版和真实聚会可玩性，再扩展更多模式。
