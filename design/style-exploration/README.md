# 美术风格探索 · 4 个备选方向

DESIGN-01（#1）的补充探索。用户在评审 PR #6 后觉得 spy-titles 做全局主风格太单一，提出 4 个备选方向。本目录把这 4 个方向做成**可对比的设计稿**，不是定稿，也不冻结任何色板或素材规则。

## 怎么比较

所有风格使用同一组数据和同一套操作，只换皮：

| 屏 | 数据 | 检查点 |
|---|---|---|
| 口头描述 | 15 字长答案「只在房门关上之后才想起来的钥匙」、禁说 2 词、脑洞指令、语音中 | 长答案完整可读、语音状态 |
| 动作表演 | 15 字长答案、剩余 8 秒、同屏模式（表演者静音） | 最后 8 秒的紧迫感、操作位置不变 |
| 你画我猜（画手视角） | 题目「伞」、画布、调色板/工具、4 条猜测、4 名玩家、按住说话 | 画布能否放进这个风格、语音和猜测列表的位置 |

- 答案字号由 `fitAnswer` 按真实字体实测宽度选档，规则与 `design/spy-titles/src/layout.mjs` 一致（单行优先，放不下再均分多行）。
- 跳过 / 猜对两个按钮在每个风格里位置、大小、含义都相同。
- 画布里的伞是程序生成的同一条路径，每个风格只改笔触和填色，模拟“玩家真的画出来的东西”在不同风格下的样子。
- 顶部约 170px 留给微信胶囊按钮和状态栏。

对比图：`export/comparison-board.png`（第一行是 PR #6 的候选 A 基线，PR #6 没有你画我猜屏）。单张：`export/{sketch|brutal|win|riso}-{verbal|charades|draw}.png`，750×1624。

## 四个方向

### 1 · 手账便签（`sketch`）
方格本底、横线卡片、和纸胶带、便利贴按钮、红笔圈出倒计时。字体：站酷快乐体。

- 优点：聚会感最强，最亲切；**和你画我猜天然契合**（画布就是一张纸，玩家的涂鸦不会显得突兀）；模式差异靠荧光笔颜色和便利贴颜色就够，不用加更多色。
- 风险：快乐体做长答案时略松散，3 行 15 字还可读，再长需要降档；元素轻微旋转、胶带、撕边会让界面显得“乱”，需要严格限制只有装饰层旋转、文字层不旋转（这版的标题卡和答案卡跟着旋转了 1-2°，正式版要改掉）。
- 实现成本：中。撕边用 `clip-path`，胶带是半透明条，纸纹是一张平铺小图。旋转元素在低端机上文字会发虚。

### 2 · 新粗野主义（`brutal`）
4px 黑描边、硬投影、大圆角、高饱和纯色块。字体：得意黑（标题）+ 思源黑体 Heavy（答案）。

- 优点：**长答案可读性最好**，层级最清楚；组件化最容易（卡片、胶囊、按钮就三种），最符合 B 方向“统一操作组件、模式只换局部图形”；你画我猜的工具栏、猜测气泡也能直接复用同一套组件。
- 风险：这几年很流行，辨识度靠插画和图标撑；颜色多了容易变成“糖果色堆砌”，要限定每屏只有 1 个主色 + 黄色强调。
- 实现成本：最低。纯 CSS 边框和 `box-shadow`，WXML 和 Canvas 都好做。

### 3 · Win98 画图（`win`）
青色桌面、灰色立体窗口、像素字、LCD 计时器、气泡提示、“画图”工具栏和 16 色调色板。字体：缝合像素 12px。

- 优点：辨识度和梗感最强；**你画我猜就是“画图.exe”**，最有记忆点；文件体积最小。
- 风险：像素字做长答案明显吃亏（这版 15 字已经降到 2 行小字号），小屏和放大字体时更差；只对有 Win98 记忆的人群有效，偏怀旧梗，不一定适合所有聚会人群；标题栏用了渐变，和候选 A 的“禁止渐变”冲突（B 不受约束，但要知道）。
- 实现成本：中。立体边框容易，但像素字必须整数倍缩放，否则不同手机 DPR 下会糊；像素图标需要单独做。
- 更适合做**限定主题皮肤**，不太适合当唯一主风格。

### 4 · Riso / 报纸拼贴（`riso`）
米色新闻纸、报头、双线分栏、两色套印错位、网点、红色印章。字体：思源宋体 Heavy。

- 优点：最有“设计感”，答案做成头条很有仪式感；画布里的网点涂色很好看。
- 风险：套印错位会降低答案清晰度（这版错位 4px，已经是上限）；网点和颗粒在大面积使用时眼睛累；**本质上和 spy-titles 一样是“印刷品”审美**，可能解决不了“单一”的问题。
- 实现成本：中偏高。网点用 `radial-gradient` 可以做，但套印依赖 `mix-blend-mode`，微信 Skyline 渲染器对它的支持**未验证**；Canvas 小游戏里需要自己画。

| | 长答案可读 | 8 秒紧迫感 | 你画我猜适配 | 组件复用 | 实现成本 | 新鲜感 |

| A spy-titles | 中 | 强 | 未做 | 中 | 高 | 中 |
| 1 手账便签 | 中 | 中 | 很好 | 中 | 中 | 中 |
| 2 新粗野主义 | 很好 | 强 | 好 | 很好 | 低 | 中 |
| 3 Win98 画图 | 差 | 中 | 很好 | 好 | 中 | 很强 |

我的建议：**2 新粗野主义做主风格的候选 B**，因为它最能保证答案可读、操作稳定，且最便宜；**1 手账便签作为第二候选**，如果更看重聚会氛围和你画我猜的“纸上作画”感。3 适合以后做限定皮肤；4 和 spy-titles 太接近，不建议作为替代。

## 字体与许可

字体不提交到仓库，`python design/style-exploration/tools/fetch_fonts.py` 下载到 `fonts/`。

| 字体 | 用途 | 许可 | 来源 |
|---|---|---|---|
| 站酷快乐体 ZCOOL KuaiLe | 手账便签 | SIL OFL 1.1 | google/fonts |
| 得意黑 Smiley Sans Oblique v2.0.1 | 新粗野主义标题 | SIL OFL 1.1 | atelier-anchor/smiley-sans |
| 缝合像素 Fusion Pixel 12px proportional zh_hans | Win98 | SIL OFL 1.1 | TakWolf/fusion-pixel-font |
| 思源黑体 / 思源宋体（Noto Sans SC / Noto Serif SC） | 新粗野主义答案、Riso | SIL OFL 1.1 | 本机已安装 |

体积提醒：快乐体 1.5 MB、得意黑 2.5 MB、像素字 7 MB，都超出小程序主包可承受的范围。正式使用时，界面固定文字可以子集化打包，题库答案是动态数据，需要按题库全字集子集化后从 CDN 用 `wx.loadFontFace` 加载，或者答案改用系统字体。

## 复现

```
python design/style-exploration/tools/fetch_fonts.py
python design/style-exploration/tools/render.py
```

`render.py` 需要 Playwright 和本机 Microsoft Edge，会从 `origin/design/spy-titles-round-screen` 读取 PR #6 的两张基线图（不提交副本）。也可以直接用浏览器打开 `explore.html`（全部 12 屏）或 `explore.html?theme=brutal&screen=charades`（单屏）。

## 需要决策的问题

1. **你画我猜和语音是否进入范围？** 当前 AGENTS.md 只做口头描述、动作表演两种模式的回合屏。这里多做一屏只是为了检验风格能不能装下画布，不代表要扩大范围；是否加入需要用户和 ChatGPT（玩法/架构）确认。
2. **线上模式下动作表演怎么玩？** 同屏时大家看着表演者；线上需要视频，否则这个模式不成立。这会影响页面结构，不只是风格。
3. **小程序还是小游戏？** WXML 页面与 Canvas 小游戏对网点、混合模式、像素字的实现成本差别很大。
4. **猜对 / 跳过由谁按？** 这版沿用 PR #6 的假设：描述者/表演者按。线上你画我猜里改成猜测者输入后自动判定。
5. 选定方向后，再对该方向做 A/B 正式比较版（只做回合页），之后才冻结色板和组件规则。
