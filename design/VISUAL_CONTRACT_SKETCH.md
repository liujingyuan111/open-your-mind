# 主风格「手账便签」视觉合同 V1.0（已冻结）

> 2026-11-21 用户在评审 PR #8 后选定 B「手账便签」为正式主风格方向。候选 A（spy-titles）的合同见
> design/VISUAL_CONTRACT.md，仅作历史参照，不再扩展。本合同冻结色板、材质和组件规则，后续素材批量扩展以本文件为准。

## 1. 风格本质

聚会桌上的实体手账：方格本底、横线卡片、和纸胶带、便利贴、荧光笔标记、红笔圈注、涂鸦线条图标。
气质目标是"朋友递过来的一本笔记本"，不是精致的文创商品图。手工感来自材质组合，不来自旋转和噪点。

## 2. 色板（冻结）

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸底 | `#f7f2e4` + 格线 `rgba(96,140,190,.16)`（34px 方格） | 页面底色 |
| 墨色 | `#2a2a2a` | 文字、涂鸦描边、边框 |
| 红笔 | `#d6372b` | 倒计时圈注、禁止词波浪线、编辑记号（只此两处半用途） |
| 卡片纸 | `#fffdf8` + 横线 `rgba(90,140,200,.26)`（55px）+ 红边线 `rgba(220,80,70,.5)` | 任务卡、计时卡 |
| 便利贴黄 | `#fff3a0` | 脑洞指令条 |
| 胶带 | `rgba(240,205,110,.78)` + 白色斜纹 | 装饰 |
| 模式荧光色 | verbal `#ff9fb0` / charades `#ffd94d` | 标题荧光笔、选中态、主按钮、进度条 |

模式荧光色由 `design/MODE_ASSETS.json` 的 `modes[].theme_assets.sketch.accent` 配置驱动；新增模式在此登记一个荧光色，不得超出一个。

## 3. 必须保留

1. **文字层一律不旋转**；只有胶带、涂鸦图标等装饰层可旋转，幅度 ≤5°。
2. 每屏一个模式荧光色 + 红笔红，不增加更多颜色；颜色多不等于变化多。
3. 操作组件（开始/跳过/猜对）跨模式完全统一：位置、大小、形状不变，只随模式换荧光填充色。
4. 答案为第一视觉主体：站酷快乐体（SIL OFL 1.1，google/fonts），按长度降档字号，长答案优先完整可读；字体缺失时回退系统字体。
5. 阴影只用 2–4px 偏移实色投影（`rgba(42,42,42,.16–.2)`），禁止大面积模糊阴影、渐变、玻璃拟态。
6. 图形是"随手涂鸦"：等宽描边、圆头线帽、允许轻微抖动的手绘路径，不做精致图标集。
7. 题目与指令是数据，素材只来自本合同的组件与配置，禁止每题单独生图。

## 4. 明确禁止

- 旋转正文、答案、按钮文字。
- 渐变填充、写实高光、玻璃拟态、重噪点滤镜。
- 精致的多色矢量插画图标。
- 每屏超过一个模式强调色。
- 把红笔用到计时圈注、禁止词、编辑记号以外的任何地方。

## 5. 回合屏组件

- TaskCard：横线卡片 + 顶部两条和纸胶带；红边线左侧为卡片内容区。
- ModeMark：涂鸦线条图标（`doodle-*.svg`），等宽墨色描边。
- PromptTitle：快乐体大字，长度降档；分类标签用模式荧光笔打底。
- TwistStrip：黄色便利贴 + 顶部居中胶带 + 红色图钉点。
- TimerSeal：计时数字外手绘红笔椭圆圈（八值 border-radius，-5°）；最后 10 秒圈加粗、数字变红。
- ActionCutout：便签式按钮，墨色 2px 描边 + 实色偏移投影，主按钮填模式荧光色。

## 6. 回合屏验收

1. 第一眼读出"桌面手账"，不是文创海报也不是通用扁平 UI。
2. 文字层零旋转；装饰层旋转 ≤5°。
3. 每屏颜色 = 纸底/墨色/红笔/一个模式荧光色/便利贴黄，无额外色。
4. 1–32 字答案完整可读；剩 10 秒高注意状态清晰。
5. 两种模式共用组件树，差异只有荧光色、涂鸦图标与规则文案。
6. 字体许可：站酷快乐体 SIL OFL 1.1；小程序端子集化 + `wx.loadFontFace` 方案落地前，线上回退系统字体（未决，见 PR #8 风险清单）。
